## Правила, общие для всех уровней

- **Одна лестница.** Уровень открывается, когда пройден предыдущий целиком. Родитель может открыть любой уровень раньше в родительской зоне (ребёнок уже умеет, или занимается с другим приложением).
- **Переключатель уровней** вверху экрана уроков: вкладки «Level 1 / Level 2 / …». Закрытые уровни видны с замком. Кнопка Play открывает последний уровень, на котором ребёнок занимался.
- **Своя дорожка** у каждого уровня, с таким же устройством: кружки в одну линию, значки тем, зелёная линия пройденного (см. SPEC 3.1).
- **Те же монеты** за задания и уроки (SPEC 3.5). Покупка стикеров от уровня не зависит: все альбомы видны сразу, и монеты с любого уровня тратятся в любом альбоме (features/stick.md).
- **Задания строятся из одних кирпичиков.** Типы заданий из SPEC 3.2–3.4 (найди картинку, найди пару, лишнее, обведи, пазл, парочки, гонки, шарики) переиспользуются на каждом уровне; новые типы добавляются в файле уровня, с пометкой, что они новые.
- **Голос.** Все инструкции уровня — записанные клипы (ElevenLabs), на трёх языках инструкций. Английские слова и звуки одни для всех языков. Новые реплики уровня перечисляются в его файле, чтобы их добавить в `app/voice.js`.
- **Один уровень = одна проверяемая гипотеза.** Уровень считается готовым, когда ребёнок 5–6 лет проходит его с родителем без объяснений словами: все инструкции понятны по картинке и голосу.

## Как писать спеку уровня

Каждый файл в одном порядке:
1. Цель: что ребёнок умеет после уровня, одной фразой.
2. Условие открытия.
3. Содержание: список единиц (слова, буквы, сочетания, фразы) и их порядок.
4. Структура дорожки: сколько уроков, из чего состоит группа уроков, таблица уроков.
5. Задания: какие переиспользуются, какие новые (с описанием экрана и реакции на ошибку).
6. Голос: список новых реплик.
7. Графика: что нужно нарисовать.
8. Открытые вопросы.
