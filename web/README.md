# Stick & Play — the web app

This folder is the whole application: a static web page (HTML, CSS, JavaScript modules, no framework, no bundler)
that runs in a browser and is packaged unchanged into the Android and iOS shells in `../app/` (SPEC 7.2).

## Run

```
npx http-server web -p 5180 -c-1 -s      # from the repository root, then open http://localhost:5180
```

Any static server works (ES modules need http://, not file://). The VS Code launch configuration in
`.claude/launch.json` starts the same server.

## Layout

| Path | What |
|---|---|
| `index.html` | The markup of every screen; links the styles and `js/main.js` |
| `css/` | One file per area, linked in order: `base` (stage, top bar, buttons, overlay), `home`, `learn` (lesson path), `lesson` (intro, quiz, trace, puzzle, pairs, lines, race), `album`, `collection`, `parent`, `startup` (first run, "Who's playing?"). Every file holds the original rules and then the storybook-skin rules that refine them; order matters. |
| `js/main.js` | Entry point: imports the screens, registers the service worker, calls `boot()` |
| `js/data.js` | Content: sticker sets, words, letters, letter teams, lesson tracks, album pages, the economy. No DOM, so `app/voice.js` imports it in Node |
| `js/icons.js` | The SVG icon set |
| `js/gen/art.js`, `js/gen/voice.js`, `js/gen/sfx.js` | Generated by `app/art.js`, `app/voice.js` and `app/sfx.js`: which stickers and backgrounds have artwork, which lines have voice clips, which stickers have a sound |
| `js/profiles.js` | Children's profiles in `localStorage`: the list, the playing one, each profile's saved game and device-only record (keys in `Specs/features/startup.md` 5) |
| `js/state.js` | The running game `S` of the playing profile (`useProfile(id)` refills it), repairs of old saves, progress helpers, the daily limit |
| `js/session.js` | Screen state that is not saved (`U`): the open screen, streak, level, album page |
| `js/stage.js`, `js/util.js` | The 1280×800 frame, scaled to fit the window, and the stage that fills the rest of the window around it (screen backgrounds bleed to the edges, edge controls follow the safe area); pointer maths in frame pixels; small pure helpers |
| `js/audio.js` | Voice (recorded clips, else speech synthesis, else the native TTS plugin), sound effects, music |
| `js/platform.js` | Browser vs Capacitor: the native TTS bridge, service worker registration, full screen on phones |
| `js/ui.js` | Coins, confetti, the overlay card, the greeting |
| `js/startup.js` | Start-up (`Specs/features/startup.md`): `boot()` reads the device, chooses the first screen (`route()`), takes the launch screen `#splash` away after 2–2.5 s; the first-run and "Who's playing?" screens; `enterHome(id)` loads a profile and counts its new day and daily coins |
| `js/nav.js` | `go(screen)`, Back, the time limit; screens register `onEnter` / `onLeave` |
| `js/lessons.js` | Builds a lesson, runs its tasks, the reward screen; task modules register with `onTask` |
| `js/quiz.js`, `js/trace.js`, `js/puzzle.js`, `js/pairs.js`, `js/lines.js`, `js/race.js` | The task types |
| `js/path.js`, `js/album.js`, `js/collection.js`, `js/parent.js` | The other screens |
| `js/voicelist.js` | Parent zone → Testing → Voices: every spoken line (ru, en), its clip or the device voice, buttons to hear both, marks for lines that sound wrong |
| `sw.js` | Service worker: the app, artwork, music and voice clips work offline in the browser |
| `manifest.json`, `icon.png` | Install to the home screen: full screen, landscape |
| `img/splash.jpg` | The launch screen picture (from `../Art/splash.png` through `app/art.js`) |
| `img/bg/` | Backgrounds: album pages by set id and `homescreen.jpg` (from `../Art/backgrounds/` through `app/art.js`) |
| `img/race/` | Race cars, the gate beam and the word signs (from `../Art/race/` through `app/art.js`; the race falls back to its SVG and CSS drawings without them) |
| `img/stickers/` | Sticker artwork (from `../Art/stickers/` through `app/art.js`) |
| `audio/` | Music, the voice clips (`app/voice.js`) and the sounds of rare and special stickers in `audio/sfx/` (`app/sfx.js`) |

## Conventions

- Shared mutable UI state lives in `U` (`session.js`); saved state in `S` (`state.js`), written with `save()` into the playing profile.
- A screen module draws itself in the function it registers with `onEnter('<id>', fn)`; `go('<id>')` never imports screens.
- Every spoken line goes through `say(...)`; new Russian lines are also added to the list in `app/voice.js`.
- Feature specs: `../Specs/features/`; the product spec: `../Specs/SPEC.md`.
